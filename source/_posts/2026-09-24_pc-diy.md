## 硬件选择

我的硬件选择思路是集思广益的，在小红书上各种发帖、寻帖总结出来的配置，不代表最优。使用了大约两个月后，也确认在预算不变的情况下有更优的配置。

主机主要有 8 大硬件，上图已经展示了，其中 CPU、显卡和内存是最重要的三个硬件，这直接决定了主机的性能上限；其次是主板和硬盘；最后是电源、散热和机箱。

关于 CPU 的选择：网上众说纷纭，如果是游戏党，大多都推荐 AMD 的卡（简称 A 卡），如果是生产力，比如 Coding、视频剪辑等，比较需要多核性能的，更推荐 Intel 的卡（简称 I 卡）。考虑到我经常需要编程，所以就选择 I 卡。I 卡中消费级 CPU 主要有 i 系列和 U 系列，其中 i 系列都会说缩缸（即硬件问题导致的 CPU 频率达不到基本标准），所以就选择了 U 系列，综合考虑价格和性能，选择购入当时的次旗舰 U265K，20 个物理核心。

关于显卡的选择：毫无疑问选择 NVIDIA 的卡（简称 N 卡），N 卡是目前的绝对主流，无论是游戏还是生产力（AI、视频编解码）等都拥有最大的社区，出了问题比较好找到解决方案。但 N 卡自 26 年 8 月开始价格骤升，性价比下降了不少。在三千预算下，只能买入门级 5060 了，8 GB 显存如果不开高画质打游戏足够了，但我不怎么玩游戏，其实完全够。

关于内存的选择：主要考虑容量、频率和品牌。考虑到开发需求，容量方面我选择了 32 GB，使用后证明这是正确的选择，WSL、Docker、Agent 客户端就会吃掉大约 50% 的内存，运行态下日常占用 85% 的内存。5000 MHz 的频率基本足够，频率越高、数据传输越快，当然对 CPU 的要求也越高。我这里购买的是 6000 MHz 的宏基掠夺者，属于二流内存中还不错的选择。默认双通道，因为双通道才能发挥出最高频率，单通道会导致降频。

关于主板的选择：主板主要看供电相数、对内存代数的支持以及尺寸，Z 系列仅次于 X 系列，支持 DDR5 代内存。次一代的 B 系列似乎只支持 DDR4 代内存，不过价格也低不少。尺寸方面主要分三类、ATX、M-ATX 和 ITX，依次减小，更大的主板一般代表更多的硬盘插槽，考虑到机箱大小和硬盘需求，我买了中型号的 M-ATX 主板。品牌方面主要有三大品牌：七彩虹、技嘉和微星，当时也没注意，这方面没有做攻略，见仁见智吧。

关于硬盘的选择：主要看颗粒，其次看容量和传输速率。颗粒方面不建议买 QLC，建议买 TLC，后者寿命更长、性能更好、稳定性更强。至于容量和传输速率就见仁见智吧。

关于电源的选择：主要看功率和品牌。功率过低会导致组件供电不足而产生不可逆的损坏，一般越大越好，但考虑到价格，一般选择各组件建议功率之和+200W 左右的功率，比如 5060 建议 200 W、U265K 建议 150 W，再算上主板供电 100 W（包括内存、硬盘等），就选择 600 到 700 W 的电源即可。品牌方面优先选择大牌，安全第一。

关于散热的选择：主要有风冷和水冷两种，风冷更安全，但高功率 CPU 很难压得住（一种装机黑话，表示散热能力不足），同时噪声也更大；而水冷散热性能更好、噪声也更小、颜值也更高，缺点就是两三年就需要更换，因为不可避免会出现漏液等情况。见仁见智。

关于机箱的选择：主要根据主板尺寸筛选，价位在 50 到 500 不等，一般考虑颜值，见仁见智。

其他硬件比如机箱风扇、显示器、摄像头、麦克风、耳机、鼠标、键盘等与主机核心不相关的外设就见仁见智了。

## 硬件组装

推荐装机视频：[【装机教程】全网最好的装机教程，没有之一](https://www.bilibili.com/video/BV1BG4y137mG/)。

组装前需要确保有基本的组装工具，最常见的比如：螺丝刀、螺丝存放盒。

所有硬件到货后，拆箱前第一时间打开手机录制拆箱视频，展示包装是否损毁，打开后展示硬件的唯一码，减少后续退换货情况下不必要的扯皮。

接下来开始组装。组装顺序一般为：

1. 拆封主板，放置在底部相对柔软的平面，避免主板底部针脚磨损。
2. CPU 涂抹硅脂并安装至主板中央，注意方向。
3. 两根内存条安装至主板的内存插槽，默认安装在 2、4 通道。
4. 硬盘安装至主板的硬盘插槽，PCIe 5.0 需要安装在离 CPU 最近的一个硬盘插槽上。
5. 将主板安装进机箱并固定。
6. 安装散热，分别与 CPU 和主板固定。
7. 供电接线，将电源的供电线分别和 CPU、显卡和主板连接，然后固定电源于机箱。
8. 数据接线，将机箱的各种外设接口连接到主板，包括灯光、耳机、麦克风、BIOS、电源开关机等。
9. 安装显卡。

最后理线、封装机箱。理线用的绑带一般电源或者机箱会配套送几根，完全够用了。各硬件的包装盒可以保留，便于后期的退换货以及二手交易。一些图例：

## 软件配置

硬件全部组装好后，就是软件配置环节。考虑到使用场景的广泛性以及操作的习惯性，我还是选择安装 Windows 系统。

1. 首先需要提前准备好一个至少 32GB 的空 U 盘用来存放 Windows 系统镜像。具体制作流程参考知乎笔记 [【保姆教程】Windows 11 24H2官方原版镜像U盘安装](https://zhuanlan.zhihu.com/p/1897086937791170205)，这里不再赘述。
2. 然后将 U 盘插入机箱的 USB 接口并开机。此时会进入一个全英的界面，该界面为主板的 BIOS 界面，找到启动选项，选择从 U 盘启动。
3. 接着主板应当会识别到硬盘，将该硬盘分区（例如分为 C、D 两个区），并将系统安装至 C 盘。安装时会弹出序列号，从咸鱼花几块钱买一个就行（这里不提倡盗版，但微软默认不管个人用户的盗版行为，如果是企业，还是得走正版渠道）。期间应该会发生几次黑屏，属于正常现象。
4. 重启后应当就是熟悉的 Windows 界面了，如果没网络可以查一下怎么在终端配置跳过网络，有网络按流程配置即可。
5. 之后需要安装驱动，特别是显卡驱动。技嘉自带 Control Center（简称 GCC），在里面安装对应的驱动并重启即可。
6. 最后需要进行烤鸡（装机黑话，指对硬件进行压力测试），这里推荐图吧小工具，不推荐鲁大师，见仁见智。

如果烤鸡没问题，整个装机基本就大功告成了，之后就安装 Office、Steam 等常用软件即可 ^_^。图吧小工具可以查看硬件属性，图例：

## 经验心得

整个装机和配置过程花了我两晚，没有任何返工就一次点亮了，用了快两个月没有任何问题。只要你稍微细心一点，提前看一遍装机视频，然后边看边装、遇到问题就查，6 个小时左右基本就完事了。当然也可以付费让别人安装，不过那样就少了一些 DIY 的乐趣了 ^_^

另外近两个月的使用下来，有一些新的建议：比如如果确认要买显卡，就没必要买带核显的 CPU，可以省小几百元，因为核显完全用不上，I 卡不带核显的 CPU 一般为型号后加一个 F 后缀，比如 U265K 就是带核显，U265KF 就不带核显。另外如果你有无线办公需求，可以选择带蓝牙和 Wi-Fi 功能的主板。
